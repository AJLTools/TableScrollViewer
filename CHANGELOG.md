# Changelog

## [1.0.0] - 2026-08-31

- First release as a Unity Package Manager (UPM) package `com.uindies.tablescrollviewer`.
- Runtime scripts (`TableScrollViewer`, `TableNodeElement`, `TableSubNodeElement`,
  `TableScrollViewerScrollbar`) moved into the `Runtime/` assembly
  `Uindies.TableScrollViewer`.
- Demo scenes, node prefabs, test scripts, textures and TextMesh Pro resources
  extracted into the importable sample `Samples~/TableScrollViewer/`
  (assembly `Uindies.TableScrollViewer.Samples`, references TextMeshPro).
